
# CppScript

**Version:** 0.1.0

**Tagline:** Write the intent. Control the execution.

CppScript is a programming language implemented in C++17.

## Development Goals

- Lexer and token diagnostics
- Parser and syntax diagnostics
- Strict type checking and type inference
- Tree-walk interpreter
- Functions, arrays, objects and classes
- Modules and exception handling

## Build Requirements

- C++17-compatible compiler
- CMake
- Git

## Status

Project setup and compiler bootstrap.
